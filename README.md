## Run Locally

1. Download or clone this repository.
2. Keep `index.html`, `atharva-profile.jpg`, and `Atharva_Dahibhate_Resume.pdf` in the same folder.
3. Open `index.html` in a web browser.

No build step is required for this static website.

## Deployment with GitHub Pages

1. Open the repository's **Settings**.
2. Select **Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and `/(root)` folder, then save.
5. Wait for GitHub Pages to finish deploying and open the published URL.
